# Core Flight System : Framework : App : Sample

This repository contains a PUS application (pus), which is a framework component of the Core Flight System.

This PUS application is a non-flight example application implementation for the cFS Bundle. It is intended to be located in the `apps/pus` subdirectory of a cFS Mission Tree. A demonstration bundle of the Core Flight System is available at <https://github.com/nasa/cFS> (which includes pus as a submodule) and includes build and execution instructions.

For information about a mission ready cFS bundle, see: <https://github.com/nasa/cFS#cfs-gov-mission-ready-version> 

pus is an example for how to build and link an application in cFS. See also the skeleton_app (<https://github.com/nasa/skeleton_app>) if you are looking for a bare-bones application to which to add your business logic.

## Known issues

As a PUS application, extensive testing is not performed prior to release and only minimal functionality is included. Note discrepancies likely exist between this application and the example detailed in the application developer guide. See all [open issues](https://github.com/nasa/pus/issues).
